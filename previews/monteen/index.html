O restaurante

Monteen, no Largo Doutor Tito Fontes

O Monteen é um restaurante de cozinha mediterrânica no Porto, no Largo Doutor Tito Fontes, 147. É uma casa de jantares: abre de quarta a domingo, a partir das 19h00.

Há esplanada para quem prefere jantar ao ar livre, e wi-fi para os clientes. Para garantir lugar, a reserva é recomendada.
